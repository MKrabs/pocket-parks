## Goal
Raid targets need parks. `scripts/bot_park.gd` (`class_name BotPark`, pure): `generate(theme_id, seed, size := "small") -> ParkMap`
(or `ZooMap` if S1 hasn't renamed it yet on your branch; keep the call sites trivial to rename).

- Entrance on an edge, a connected path network (a spine plus a couple of branches), attractions and
  shops placed next to paths, decor sprinkled around, using only buildings of that theme. Valid placement
  everywhere (`can_place`).
- Sizes: `small` (about 3 attractions, 1–2 shops), `large` (about 6 attractions, 3 shops, more decor).

## Acceptance
- `tests/test_bot_park.gd`: for 20 seeds × both themes, exactly one entrance, every attraction/shop
  touches a path tile, all path tiles connected to the entrance, and the same seed gives the same park.
- `./gd check` ok. `shots/B1.png` from a showcase script: one zoo and one festival bot park side by side
  (or two shots).
