## Goal
Make the prototype playable as a builder: pick a building, place it on the grid, remove it.

- `scripts/zoo_map.gd` (`class_name ZooMap`, pure logic): occupancy of the 16×16 grid, `can_place(id, cell)`
  (in bounds, all footprint tiles free), `place(id, cell)`, `remove_at(cell)` (removes the whole building
  that covers the cell, refunds half the cost), `money: int` (start 500; placing costs `cost`; refused if too poor).
- A build bar along the bottom of the screen (Control nodes, built in code): one squircle button per
  catalog building with its name and cost, plus an "eraser". Soft rounded StyleBoxFlat (corner radius,
  palette colours, no default Godot grey theme). Money shown top-left with a BUTTER chip.
- Ghost preview under the mouse: the selected building drawn semi-transparent on the hovered cell, tinted
  `Palette.CORAL` when `can_place` is false. Left-click places, right-click or the eraser removes.
- Buildings draw in correct iso depth order (back to front by cell x+y, using the footprint's front edge).
- Seed the map at start with a few buildings (an enclosure, a pond, some trees and a path) so the
  screenshot isn't empty.
